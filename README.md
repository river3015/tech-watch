# tech-watch

インターネット上の技術情報を定期的に収集し、新着情報をまとめて通知する仕組み。

## 目的

公式情報や技術ブログを継続的にチェックし、興味のある技術情報を効率よく把握できるようにする。毎日などの定期的なタイミングで、「こういう情報がありました」と新着情報を受け取れることを目指す。

## 収集対象の候補

- Linux Foundationなどの技術団体の公式情報
- ベンダーの公式発表、公式ブログ、技術情報
- Zenn、Qiitaなどの技術記事プラットフォーム
- メガベンチャーなどの企業が公開するテックブログ

※ 発話中の「Zend」「Kita」は、文脈からZenn・Qiitaを指すと推測して記載している。対象サービスは今後確定する。

## 想定する動作

1. 登録した情報源から定期的に技術情報を収集する。
2. 前回までに収集した情報と比較し、新着情報を抽出する。
3. 記事タイトル、出典、リンク、必要に応じた概要をまとめる。
4. 毎日などの設定したタイミングで利用者に通知する。

## 今後決めること

- 収集方法（RSS / Atom、APIなど）
- 収集・通知の頻度と実行時刻
- 通知先と通知方法
- 実行環境、収集履歴の保存方法
- 概要の作成方法や情報の絞り込み条件
